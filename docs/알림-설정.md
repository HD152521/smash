# 알림 설정 — 남은 단계

인앱 배너는 **이미 동작합니다**. 아무 설정도 필요 없습니다.
웹 푸시(앱을 닫아둬도 오는 알림)만 아래 두 단계가 남았습니다.

---

## 1. Edge Function 배포

발송기가 아직 서버에 올라가 있지 않습니다. 코드는 `supabase/functions/send-push/`에 있습니다.

```bash
npx supabase login          # 브라우저가 열립니다 (1회)
npx supabase link --project-ref vwocyjuwormeaentdost
npx supabase functions deploy send-push
```

## 2. 비밀키를 Supabase에 등록

VAPID 키는 이미 만들어져 `.env.local`에 있습니다. 그 값을 Supabase에도 넣어야 발송기가 서명할 수 있습니다.

```bash
# .env.local 에서 값을 복사해 넣습니다. 채팅창에 붙여넣지 마세요.
npx supabase secrets set \
  VAPID_PUBLIC_KEY="<VITE_VAPID_PUBLIC_KEY 값>" \
  VAPID_PRIVATE_KEY="<VAPID_PRIVATE_KEY 값>" \
  VAPID_SUBJECT="mailto:wkdrndydtlr@gmail.com"
```

## 3. Vercel 환경변수

**공개키만** 넣습니다. 이게 없으면 브라우저가 구독을 만들 수 없어
설정 화면에 "알림 서버가 아직 설정되지 않았습니다" 가 뜹니다.

```
VITE_VAPID_PUBLIC_KEY = <.env.local 의 값>
```

> `VAPID_PRIVATE_KEY`, `SUPABASE_SECRET_KEY`, `SUPABASE_DB_URL`은
> Vercel에 넣지 않습니다. 브라우저로 나가지 않더라도 보관처를 늘릴 이유가 없습니다.

## 확인 방법

1. 배포된 사이트에서 대회 → 설정 → **알림 켜기**
2. 다른 계정(관리자)으로 그 사람이 들어간 경기를 편성
3. 폰에 알림이 오는지 확인

DB 쪽이 제대로 도는지는 언제든 확인할 수 있습니다.

```bash
npm run db:smoke:notify     # 알림 대상 · 권한 16개 검사
npm run db:smoke:push       # 발송기가 실제로 서명·암호화해 푸시 서비스까지 닿는지
```

## 아이폰 주의사항

iOS는 **홈 화면에 추가한 경우에만** 웹 푸시를 받습니다. 사파리 탭으로 열어둔
상태로는 알림이 오지 않습니다. 애플 정책이라 앱에서 바꿀 수 없습니다.

앱이 알아서 감지해서, 아이폰 사용자에게는 설정 화면에 설치 방법 3단계를 보여줍니다.
설치하지 않은 아이폰 사용자에게는 **인앱 배너가 유일한 알림**입니다.

## 지금 알리는 시점

**코트 대기 순번이 앞으로 당겨졌을 때** → 그 경기에 **뛰는 선수 전원 + 지정된 심판**에게.

```
1번 코트   [진행 중]  1조 vs 2조
           대기 1     3조 vs 4조   ← 알림 감
           대기 2     1조 vs 3조   ← 알림 감
           대기 3     2조 vs 4조   ← 아직
```

기본값은 **2번째 이하**이고, 대회 설정(관리 → 경기 규칙 → 알림)에서 바꿉니다.
`config.readyQueuePosition` 입니다.

앞 경기가 시작되면 줄이 한 칸씩 당겨지고, 그때 3번째였던 사람에게 알림이 갑니다.
바뀐 행은 앞 경기 하나뿐이므로, 트리거는 바뀐 행이 아니라 **그 코트의 줄 전체**를
다시 셉니다 (`notify_up_next`).

한 경기에 한 사람당 한 번만 갑니다 (`unique (match_id, user_id, kind)`).
관리자가 대진표를 정리하는 동안 순번이 흔들려도 다시 울리지 않습니다.

알리지 않는 경우:
- 코트를 아직 안 정한 경기 (순번이 없습니다)
- 수동 기록 (이미 끝난 경기를 장부에만 남기는 것)
- 방금 그 줄을 건드린 본인 (자기가 한 일을 자기 폰이 알릴 이유가 없습니다)

> 예전에는 **코트가 배정되는 순간** 알렸습니다(`kind = 'court_assigned'`).
> 앞에 다섯 경기가 밀려 있어도 똑같이 울려서, 알림이 온 시점과 몸을 풀어야 할
> 시점이 너무 멀었습니다. 이미 쌓인 행 때문에 옛 `kind` 값은 남겨 뒀습니다.

다른 시점(경기 시작 임박 등)을 추가하려면 `notification_outbox`의
`kind`를 늘리고 `pending_notifications`의 문구 분기와
`useInAppNotifications`의 배너 문구를 함께 늘리면 됩니다.
